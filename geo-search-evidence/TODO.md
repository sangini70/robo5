# Task Management Rules

- 새로운 작업은 Backlog에 추가한다.
- 작업을 시작하면 In Progress로 이동한다.
- 검토와 테스트가 완료되면 Completed로 이동한다.
- 완료된 작업은 삭제하지 않는다.
- TODO.md는 프로젝트의 현재 진행 상태를 나타내는 Source of Truth이다.
